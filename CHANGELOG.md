# Changelog

Changes are recorded here rather than scattered through troubleshooting instructions. No historical version numbers or release dates have been reconstructed.

## Unreleased

### Documentation

- Split installation, configuration, web usage, storage, and operational guidance into linked guides.
- Clarified shipped configuration values, request-triggered retention, metadata backups, and current archive/star limitations.
- Replaced unsafe manual ingest guidance and unavailable deployment instructions with safety notes and a code-only update/rollback procedure.
- Added GitHub Markdown and local-link validation.

### Current Feature Baseline

These features already exist in the source; this list does not assert when they were released:

- Date browsing, camera/search filters, thumbnails and duration badges.
- Archived playback with a retention-storage notice and calendar indicators.
- Dashboard counts and sizes for active and archived MP4s.
- Shared starred clips stored in persistent metadata and listed by date.
- Retention, optional Nextcloud verification before retention deletion, Pushover and web service controls.
