Nextcloud Sync

When enabled and retention mode is "Delete", each date folder is uploaded to Nextcloud via rclone and verified before it's allowed to be deleted. The rclone remote must already be configured on this Pi (rclone config) before enabling this.

Notifications (Pushover)

Notifies you when clips are ingested, when an ingest cycle fails or triggers a USB watchdog reset, when retention cleanup runs, and when a Nextcloud upload or verification fails. Get your token/user key at pushover.net.

Video Playback

Controls how much each clip loads before you press play. None is recommended and shows a duration badge (pre-computed at ingest time, no browser request needed) plus a custom play button — the real player only loads once you click it. Metadata reverts clips to the plain native video player (no badge, no custom play button) and makes the browser fetch metadata for every visible clip on page load — with many clips on one page this can trigger a burst of simultaneous requests that has caused real crashes on this setup before. The duration badge already shows accurate duration under None, so Metadata provides no extra information — only the same risk it was built to avoid. Auto is disabled for now: a separate, still-unconfirmed crash is under investigation pending a hardware fix, so this option isn't safe to offer until that's resolved.

Timing & Watchdog

Settle time — how long Watchman waits after the last write to the virtual drive before ingesting clips. Lower values ingest sooner; too low may catch incomplete writes.
Min interval — minimum gap between ingest cycles even if new writes are detected, to avoid cycling too frequently.
Network watchdog — if the Pi loses internet connectivity for longer than the timeout, it reboots automatically to recover. Disable during maintenance to prevent unexpected reboots. Changes take effect after restarting the Network Watchdog service below.
